# 04 · Test matrix

How I test whitelisted creator ads: what to test, in what order, and when to stop.

---

## What to test (in this order)

| Round | Variable | Why this order |
|---|---|---|
| 1 | **Creator** | Biggest swing in results. Find who the audience trusts first. |
| 2 | **Hook** | Same creator, same body, 3 openings. Cheapest big win. |
| 3 | **Format** | Reel vs Story vs Feed, talking head vs demo. |
| 4 | **Audience** | Broad vs interest vs lookalike, once creative is proven. |
| 5 | **Offer / CTA** | Only once creative and audience are stable. |

**Change one variable per round.** If everything changes at once, you learn nothing.

---

## Kill rules (set before launch)

Write these down before the test starts. Adjust the numbers to your account's benchmarks.

| Signal | Rule |
|---|---|
| **Spend cap without results** | Pause if spend reaches [2–3×] target CPL with no leads |
| **Hook failure** | Pause if CTR is well below your account average after enough impressions to judge |
| **Lead quality** | Pause if leads come in but fewer than [x]% qualify |
| **Fatigue** | Refresh when frequency rises and CTR keeps falling week on week |
| **Usage window** | Hard stop on the agreed end date, whatever the results |

## Scale rules

| Signal | Action |
|---|---|
| Beats target cost per qualified lead for [7] days | Increase budget gradually (e.g. 20–30% steps) |
| One hook clearly wins | Recut the winner from raw footage; brief the creator for more in that style |
| One creator clearly wins | Extend usage, request account-level permission, brief a second piece |

---

## How I judge results

1. **Cost per qualified lead** (or cost per activated user for apps), not CPL alone
2. **CTR and hold rate** to diagnose the hook
3. **Landing page conversion rate** to diagnose the offer and page
4. **Comparison vs the brand control** to prove whitelisting's value
